Answer key
1. According to this paper, why does the Transformer train faster than recurrent models?
A. ✗ It replaces gradient descent with a closed-form solution for attention weights
Why not: The model is trained with the Adam optimizer, a gradient method.
B. ✗ It uses far fewer parameters than any recurrent model it was compared with
Why not: The paper credits parallelism, not a smaller parameter count.
C. ✓ Self-attention relates all positions at once, so computation within a layer runs in parallel
D. ✗ It skips positional information entirely, which removes a costly step
Why not: The paper adds positional encodings because attention has no sense of order.
Explanation: Recurrent layers must process tokens one after another; self-attention needs only a constant number of sequential steps per layer.
2. What does multi-head attention give the model, according to the authors?
A. ✗ A way to avoid computing attention weights for padding tokens
Why not: Masking handles padding and future positions, not multiple heads.
B. ✗ A guarantee that every head learns the same alignment
Why not: The point of several heads is that they can learn different patterns.
C. ✗ A replacement for the feed-forward layers in each block
Why not: Each block keeps a position-wise feed-forward layer after attention.
D. ✓ The ability to attend to information from different representation subspaces at once
Explanation: A single head averages over everything; several heads let the model look at different kinds of relationships in parallel.
3. According to this paper, the Transformer still relies on a recurrent layer in the encoder.
Answer: False
Explanation: The architecture drops recurrence and convolution entirely and uses only attention plus feed-forward layers.
4. According to this paper, dot products are scaled by 1/√dₖ because large values push softmax into regions with tiny gradients.
Answer: True
Explanation: Without scaling, dot products grow with dimension and the softmax saturates.
5. In your own words, why does the model need positional encodings?
Model answer: Attention treats its input as a set, so without added position signals the model cannot tell word order.
Explanation: The authors add sinusoidal encodings to the input embeddings so the model can use the order of the sequence.
If you remember one thing
Self-attention alone, with no recurrence or convolution, is enough for strong sequence transduction, and it trains much faster because it parallelizes across positions.
